# Welcome to RAG SDK

<div style="text-align: center; margin: 0.5rem 0 0.3rem 0; font-family: 'Avenir Next', 'Avenir', 'Century Gothic', 'Segoe UI', sans-serif;">
  <span style="font-size: 4.5rem; font-weight: 300; letter-spacing: 0.02em;">RAG SDK</span>
</div>

RAG SDK is a knowledge retrieval-augmented development kit for large language models on the Ascend platform. It provides modular APIs to address issues such as slow knowledge updates and weak responses to questions in specialized domains. This documentation repository provides guidance on RAG SDK.
